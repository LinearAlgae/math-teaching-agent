    一直以來，數學被認為是一門最難學的課程，也常常被認為跟現
實生活嚴重脫節的知識，可是，她卻是眾所公認的科學之母，造成這
個落差因素很多，也不是一個三言兩語足以道盡的議題。任何知識，
只要有一定的張度，就會有一定的難度，就一位數學老師的基本職責，
應該竭盡所能，讓學生享受跨越數學難度的成就感所帶來的學習樂趣，
讓國民義務階段的數學知識成為一種國民的基本素養，一種與生活息
息相關的必備知識。終生學習是一種生命的態度，數學老師們更需要
秉持這種態度，不斷探索我們習以為常的數學與數學教學，如此，方
能改善眼前數學教育的困境。 
很幸運的，我有許許多多的機會，讓我察覺到自己對國民教育階
段數學認知的淺薄，也因此而得以自我鞭策並不斷拓展對數學教與學
的視野，這個過程讓我樂在其中，因此，很想分享我對國民教育階段
數學的觀點，從為什麼要學它，以及，學了之後有甚麼用的角度，來
思考我們應該給學生學甚麼樣的數學。趁著分析剛頒布的綱要課程手
冊，將個人的淺見做標示與註記，希望這些資料能幫助現場老師對數
學的學科本質有更清楚的認識，以及匯集一些心中的疑問作為往後課
綱編修的參考，敬請指教！

### 一、 文字內容（理論說明）

圖片上方的文字是關於幾何縮放的核心定理和概念解釋，主要分為幾個部分：

**1. 縮放的性質 (第1-4點)：**
*   **圖形的縮放與比例：** 說明透過圖形的縮放可以了解縮放後的邊長成比例，對應角保持不變。
*   **縮放中心與位置：** 強調了縮放中心點位置的不同會影響縮放後的圖形位置，但若縮放比例固定，則這些縮放後的圖形皆全等（相似性）。
*   **相似的定義：** 定義了兩個平面圖形是相似的條件：經過縮放動作後，其中一個圖形與另一個圖形全等，且對應角相等、對應邊長成比例。
*   **多邊形的相似性：** 說明兩個邊數相同的多邊形，若對應角相等且對應邊長成比例，則它們是相似的。

**2. 關鍵術語註釋：**
*   **(註3)：** 指出縮放中心可以看作是圖形的消失點。

*   **角相等關係：** 強調了三角形中只要有兩組對應角相等，則第三組也必然相等。

#### 3. 直角三角形中的相似 (Similarity in Right Triangles)
*   **垂線應用：** 以直角三角形 $\triangle ABC$ 為例，說明如何利用斜邊上的高（垂線）來建立相似三角形。
*   **比例關係的推導：** 展示了在直角三角形中，兩組相似三角形之間的對應邊長比關係，例如：
    $$AB = BC \cdot \frac{BD}{BC}, \quad AC = BC \cdot \frac{DC}{BC}, \quad AD = BD \cdot \frac{CD}{BC}$$
*   **教學觀點強調：** 強調學生應學習相似後對應邊長比的關係，而非僅背誦公式。

#### 4. 隱性的勾股弦定理 (Implicit Pythagorean Theorem)
這部分是內容的核心數學定理的引導：
*   **註6說明：** 提出在所有非直角三角形中，從一個頂點向對邊割出線段只能得到一個相似三角形。
*   **母子定理應用：** 指出只有在直角三角形中（利用垂線），才能同時得到兩個相似的三角形 $\triangle DBA$ 和 $\triangle DAC$。
*   **核心公式：** 引入了勾股弦關係 $d^2 = x \cdot y$，並將其用於判別角度類型：
    *   若 $d^2 < x \cdot y$，則角為銳角。
    *   若 $d^2 = x \cdot y$，則角為直角。
    *   若 $d^2 > x \cdot y$，則角為鈍角。
*   **類比：** 將此與畢氏定理 $a^2 + b^2 = c^2$ 進行類比。

### 一、 主要定理/敘述部分 (Theorem Statement)

圖片頂部列出了核心的數學定理或命題：

**核心論點：** 利用截線段成比例線段來判別兩直線是否平行。

**數學內容詳述：**
在 $\triangle ABC$ 中，假設 $D$ 在 $AB$ 上，$E$ 在 $AC$ 上，如果滿足以下比例關係之一成立：
$$AD : DB = AE : EC \quad (\text{或 } AD : AB = AE : AC \text{ 或 } AB : DB = AC : EC)$$

**結論是：**
1. 則線段 $DE$ 平行於 $BC$ ($DE \parallel BC$)。
2. 並且比例關係成立：$AD : AB = DE : BC$。

### 二、 釋例 (Examples)

圖片列出了七個相關的例子，旨在幫助學生理解和應用上述定理，並討論其前提條件的重要性。

*   若在 $\triangle ABC$ 中，有一直線（截線）將三角形的兩邊截成比例線段，則該直線必平行於此三角形的第三邊。

    *   或 $AD:AB = AE:AC$
    *   或 $AB:DB = AC:EC$
*   **結論 (Conclusion):** 若上述比例關係成立，則 $DE$ 平行於 $BC$，並且 $AD:AB = DE:BC$。

**圓周角度數的求法的三種模式：**

1.  **第一種情況：圓心在弦上**
    *   以 $\angle ABC$ 為例，連接 $OA$（其中 $O$ 為圓心）。
    *   證明 $\triangle OAB$ 是等腰三角形（因為 $OA = OB$），得出 $\angle B = \angle BAO$，且 $\angle AOC = \angle B + \angle BAO = 2\angle B$。
    *   由於 $\angle AOC$ 等於弧 $AC$ 的度數，所以 $2\angle B = \text{弧 } AC$ 的度數，因此 $\angle B = \frac{\text{弧 } AC \text{ 的度數}}{2}$。

2.  **第二種情況：圓心在圓周角內**
    *   以 $BO$ 交圓於 $D$ 點為例。
    *   根據第一種情況，得出 $\angle ABD = \frac{\text{弧 } AD \text{ 的度數}}{2}$，$\angle DBC = \frac{\text{弧 } DC \text{ 的度數}}{2}$。
    *   則 $\angle ABC = \angle ABD + \angle DBC = \frac{\text{弧 } AD \text{ 的度數}}{2} + \frac{\text{弧 } DC \text{ 的度數}}{2} = \frac{\text{弧 } AD + \text{弧 } DC}{2} = \frac{\text{弧 } ADC \text{ 的度數}}{2}$。

3.  **第三種情況：圓心在圓周角外**
    *   以 $BO$ 交圓於 $D$ 點為例。
    *   根據第一種情況，得出 $\angle ABD = \frac{\text{弧 } AC \text{ 的度數}}{2}$，$\angle CBD = \frac{\text{弧 } CD \text{ 的度數}}{2}$。
    *   則 $\angle ABC = \angle ABD - \angle CBD = \frac{\text{弧 } AC \text{ 的度數}}{2} - \frac{\text{弧 } CD \text{ 的度數}}{2} = \frac{\text{弧 } AC - \text{弧 } CD}{2} = \frac{\text{弧 } AD \text{ 的度數}}{2}$。

1.  **第一種情況：圓心在弦上 (例如 $\angle ABC$)**

2.  **第二種情況：圓心在圓周角內 (例如 $\angle ABC$)**
    *   連接 $BO$ 交圓於 $D$ 點。
    *   論證得到：$\angle ABD = \frac{1}{2} AD$ 弧的度數，$\angle DBC = \frac{1}{2} DC$ 弧的度數。
    *   因此 $\angle ABC = \angle ABD + \angle DBC = \frac{1}{2} AD$ 弧的度數 + $\frac{1}{2} DC$ 弧的度數 $= \frac{1}{2} (AD + DC)$ 弧的度數 $= \frac{1}{2} AC$ 弧的度數。
    *   結論：$\angle ABC = \frac{1}{2} AC$ 弧的度數。

3.  **第三種情況：圓心在圓周角外 (例如 $\angle ABC$)**
    *   連接 $BO$ 交圓於 $D$ 點。
    *   論證得到：$\angle ABD = \frac{1}{2} ACD$ 弧的度數，$\angle CBD = \frac{1}{2} CD$ 弧的度數。
    *   因此 $\angle ABC = \angle ABD - \angle CBD = \frac{1}{2} ACD$ 弧的度數 - $\frac{1}{2} CD$ 弧的度數 $= \frac{1}{2} (ACD - CD)$ 弧的度數 $= \frac{1}{2} AC$ 弧的度數。

**總結：**
*   綜合這三種情況可知，圓周角的度數等於所對弧度數的一半。這是最重要的一個圓周角。

**結論（第4段）：**
*   半圓所對的圓周角是直角。如下圖所示，$AC$ 是圓的直徑，$B$ 點在圓周上，則 $\angle ABC = AC$ 半圓度數的一半 $= 90^{\circ}$。

* **四分位數 ($Q_1, Q_2, Q_3$) 的意義：** 說明了如何運用累積相對次數分配表找出這三個關鍵點。

    * 四分位距 (Interquartile Range)：定義為第3四分位數與第1四分位數的差，即 $Q_3 - Q_1$。
* **盒狀圖的作用：** 說明盒狀圖可以表徵數據的集中程度，它是由最大值、最小值與四分位數構成，用來觀察四分位距和全距間的差異性，以及數據集中在 $Q_1$ 到 $Q_3$ 附近的狀態。
