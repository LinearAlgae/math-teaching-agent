### 第一部分：三角形全等的判斷 (Congruence)

這部分詳細列出了幾種利用邊角關係證明兩三角形全等的定理。所有範例都以 $\triangle ABC$ 和 $\triangle DEF$ 為對象。

#### (3) 角邊角全等 (ASA 全等)
*   **已知條件：** $AB = DE$ (兩邊相等)，$\angle A = \angle D$，$\angle B = \angle E$ (兩個對應的角相等)。
*   **結論：** $\therefore \triangle ABC \cong \triangle DEF$ (ASA 全等)。

#### (4) 角角邊全等 (AAS 全等)
*   **已知條件：** $AB = DE$ (兩邊相等)，$\angle A = \angle D$，$\angle C = \angle F$ (兩個對應的角相等，以及一組邊相等)。
*   **結論：** $\therefore \triangle ABC \cong \triangle DEF$ (AAS 全等)。

#### (5) 直角三角形的全等 (RHS 全等)
*   **已知條件：** $AB = DE$ (兩邊相等)，$AC = DF$ (另外兩邊相等)，$\angle C = \angle F = 90^\circ$ (兩三角形都是直角三角形)。
*   **結論：** $\therefore \triangle ABC \cong \triangle DEF$ (RHS 全等)。

#### (6) 直角三角形的全等 (SSS 全等)
*   **已知條件：** $AB = DE$， $AC = DF$，$\angle C = \angle F = 90^\circ$。
*   **證明過程（使用畢氏定理）：**
    *   根據畢氏定理，計算 $\triangle ABC$ 中 $BC$ 的長度： $AB^2 = AC^2 + BC^2$
    *   計算 $\triangle DEF$ 中 $EF$ 的長度： $DE^2 = DF^2 + EF^2$
    *   由已知條件 $AB=DE$ 和 $AC=DF$，可以推導出 (BC) $= (EF)$。
*   **結論：** $\therefore \triangle ABC \cong \triangle DEF$ (SSS 全等)。

### 一、 理論與定義部分（相似性）

圖片的開頭部分提供了關於三角形相似性的基本定義和應用：

**1. SSS 相似 (Side-Side-Side Similarity):**
*   **情境：** 在 $\triangle ABC$ 和 $\triangle DEF$ 中。
*   **判斷依據：**
    *   $\overline{AB} : \overline{DE} = \overline{BC} : \overline{EF} = \overline{CA} : \overline{FD}$ (表示三組對應邊長成比例)
    *   這等價於寫成：$\overline{AB} = (2) : (3)$ ...（省略了具體的數字，但指示是三組邊長的比例相等）
*   **結論：** $\therefore \triangle ABC \sim \triangle DEF$ (SSS 相似)。

**2. SAS 相似 (Side-Angle-Side Similarity):**
*   **情境：** 在 $\triangle ABC$ 和 $\triangle DEF$ 中。
*   **判斷依據：**
    *   $\overline{AB} : \overline{DE} = \overline{BC} : \overline{EF}$ (兩組對應邊長成比例)
    *   $\angle B = \angle E$ (兩個對應角相等)
*   **結論：** $\therefore \triangle ABC \sim \triangle DEF$ (SAS 相似)。

### 二、 全等的三角形判斷練習題（七、 「全等的三角形」在哪裡呢？）

這部分提供了五個需要根據已知條件找出全等三角形並寫出依據的例題：

**1. 例題 1：**
*   **已知條件：** $\overline{CA} = \overline{CB}$，$\overline{AD} \perp \overline{BC}$，$\overline{BE} \perp \overline{AC}$。
*   **結論及依據：** $\triangle CAD \cong \triangle CBE$ (AAS 全等)。

**2. 例題 2：**
*   **已知條件：** $\triangle ABC$ 為等腰直角三角形（暗示 $\angle B = \angle C = 90^\circ$ 或 $\angle B = \angle C$），過頂點 $A$ 作一直線 $L$，並從 $B、C$ 兩點向 $L$ 作垂線交於 $D、E$。
*   **結論及依據：** $\triangle ABD \cong \triangle CAE$ (AAS 全等)。

**3. 例題 3：**
*   **已知條件：** 五邊形 $ABCDE$ 中有一正三角形 $ACD$，且 $\overline{AB} = \overline{DE}$，$\overline{BC} = \overline{AE}$。
*   **結論及依據：** $\triangle ABC \cong \triangle DEA$ (SSS 全等)。

**4. 例題 4：**
*   **已知條件：** $\angle 1 = \angle 2$，$\overline{CD} \perp \overline{AD}$，$\overline{CB} \perp \overline{AB}$。
*   **結論及依據：** $\triangle ABC \cong \triangle ADC$ (AAS 全等)。

**5. 例題 5：**
*   **已知條件：** 四邊形 $ABCD$ 是正方形，$P$、$Q$ 分別為 $AB$、$BC$ 之中點，延長 $\overline{PQ}$ 交直線 $\overline{DC}$ 於 $R$ 點。
*   **結論及依據：** $\triangle PBQ \cong \triangle RCQ$ (ASA 全等)。
