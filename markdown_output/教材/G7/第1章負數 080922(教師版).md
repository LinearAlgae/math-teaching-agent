5. 前面「」中的語詞都有對應的相反語詞，而且有互相抵銷的關係； 
在數學上，如果甲、乙是兩個可以互相抵銷的量， 
當我們認定甲為正數量，那麼乙就為負數量。反之， 
當我們認定乙為正數量，那麼甲就為負數量。 
6. 我們可以利用「負」來表現相反。 
譬如說：賠錢的相反是賺錢，記為「負」賠錢。 
右轉的相反是左轉，記為「負」右轉。 
溫度下降的相反是溫度上升，記為「負」溫度下降。 
7. 也有不少語詞，雖然具有相反的意義，卻沒有互相抵銷的關係。 
譬如說：「有」和「沒有」、「冷」和「熱」、「新」和「舊」。

**核心數學運算與推導：**
1.  **初始計算：** 阿志收到優點卡8張和缺點卡3張，經過互相抵銷後，結算結果等於優點卡5張。（雖然此處的具體步驟略有跳躍，但目的是引導到負數運算。）
2.  **表達式建立：** 優點卡 8 張 ＋ 缺點卡 3 張
    $$= \text{優點卡}(5) \text{張} + \text{優點卡}(3) \text{張} + \text{缺點卡}(3) \text{張}$$
    $$= \text{優點卡}(5) \text{張}$$
3.  **簡記與化簡：** 將「正8」簡記為「正8」，「負3」簡記為「負3」，化簡為：
    $$\text{正}8 + \text{負}3$$
    $$= (\text{正}5) + (\text{正}3) + (\text{負}3)$$
    $$= (\text{正}5)$$
4.  **進一步化簡：** 將「正8」簡記為「＋8」，「負3」簡記為「－3」，化簡為：
    $$(+8) + (-3)$$
    $$= (+5) + (+3) + (-3)$$
    $$= (+5)$$
5.  **最終結果展示：** 最後的步驟將運算過程整理成負數加法的形式，並得出結果。
