時，溫度為16 度。 
 
 
 
 
車越開越高，中午12 點到達合歡山松雪
樓，溫度只有2 度。 
 
 
一到傍晚氣溫降到零下1 度，看來是有機
會看到雪了。 
 
 
吃完晚餐，外面的夜空無比漂亮，好
多星星，好明亮！

這張教材頁面旨在幫助學生理解**絕對值**的定義和應用，並將其延伸到數線上兩點之間的距離計算，以及如何使用中點公式來求座標。它結合了概念解釋、數學運算練習和視覺化的數線圖表。
