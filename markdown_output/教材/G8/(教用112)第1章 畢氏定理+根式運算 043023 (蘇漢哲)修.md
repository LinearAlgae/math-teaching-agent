**4. 註釋與教學重點**
*   **註釋：** 提到「行走梯不符合職業安全衛生法」，這可能是在強調實際操作中的安全和規範性。

**A. 根號加減運算的性質探討：**
教材通過反例說明根號無法直接相加或相減：

1.  **關於 $\sqrt{5} + \sqrt{3}$：**
    *   提出 $\sqrt{5} + \sqrt{3}$ 是否會是 $\sqrt{8}$？（否）
    *   推導出：$(\sqrt{5})^2 + (\sqrt{3})^2 = 5 + 3 = 8$。
    *   因此，教材指出：$$\sqrt{(\sqrt{5})^2 + (\sqrt{3})^2} = \sqrt{8}$$
    *   但結論是：$$\sqrt{5} + \sqrt{3} \neq \sqrt{8}$$

2.  **關於 $\sqrt{5} - \sqrt{3}$：**
    *   提出 $\sqrt{5} - \sqrt{3}$ 是否會是 $\sqrt{2}$？（否）
    *   推導出：$(\sqrt{5})^2 - (\sqrt{3})^2 = 5 - 3 = 2$。
    *   因此，教材指出：$$\sqrt{(\sqrt{5})^2 - (\sqrt{3})^2} = \sqrt{2}$$
    *   但結論是：$$\sqrt{5} - \sqrt{3} \neq \sqrt{2}$$

**B. 畢氏定理應用（直角三角形）：**

圖中展示了一個直角三角形，其中兩側已知邊長為 $\sqrt{3}$ 和 $\sqrt{5}$，第三邊標註為 $y$。

*   **圖形描述：** 是一個直角三角形，其兩條直角邊的長度分別是 $\sqrt{3}$ 和 $\sqrt{5}$，斜邊的長度為 $y$。
*   **應用畢氏定理：** 根據畢氏定理 $(a^2 + b^2 = c^2)$，則：
    $$(\sqrt{3})^2 + (\sqrt{5})^2 = y^2$$
    $$3 + 5 = y^2$$
    $$8 = y^2$$
    $$\mathbf{y = \sqrt{8} = 2\sqrt{2}}$$

*   **圖表/已知數值:** 提供了三個數字作為參考：160, 340, 80。
*   **計算過程 (涉及畢氏定理):**

    *   由畢氏定理可得：$340^2 = (\text{x} + 80)^2 + 160^2$
