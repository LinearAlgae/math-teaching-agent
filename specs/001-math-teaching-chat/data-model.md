# Data Model: Math Teaching Chat Application

**Date**: 2026-05-16
**Feature**: 001-math-teaching-chat

## Entities

### UserMessage

Represents a single input from the user to the system.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| id | string (UUID) | Yes | Unique message identifier |
| timestamp | ISO 8601 datetime | Yes | When the message was sent |
| text | string | Yes | User's text input (may be empty if image-only) |
| images | ImageAttachment[] | No | Attached image files (0, 1, or multiple) |
| role | enum: "student" \| "teacher" \| "auto" | Yes | User role; "auto" means infer from content |

**Validation rules**:
- At least one of `text` or `images` must be present
- Each image must be under 10MB
- Supported image formats: PNG, JPEG, WebP

### ImageAttachment

Represents an uploaded image file.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| id | string (UUID) | Yes | Unique attachment identifier |
| filename | string | Yes | Original filename |
| mimeType | string | Yes | Image MIME type (image/png, image/jpeg, image/webp) |
| sizeBytes | integer | Yes | File size in bytes |
| data | base64 string | Yes | Image data encoded as base64 for API transmission |
| extractedText | string | No | OCR-extracted text (populated after processing) |

### SystemResponse

Represents a teaching response generated by the system.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| id | string (UUID) | Yes | Unique response identifier |
| timestamp | ISO 8601 datetime | Yes | When the response started |
| completedAt | ISO 8601 datetime | No | When streaming completed (null while streaming) |
| content | string | Yes | Full response text with LaTeX math notation |
| status | enum: "streaming" \| "complete" \| "error" | Yes | Current response state |
| errorMessage | string | No | Error description if status is "error" |
| pedagogyPhase | enum: "slow-foundation" \| "fast-derivation" \| "slow-reflection" | No | Current NHM teaching phase (for streaming progress) |

### ConversationSession

Represents a continuous interaction session between a user and the system.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| id | string (UUID) | Yes | Unique session identifier |
| createdAt | ISO 8601 datetime | Yes | Session creation time |
| lastActivityAt | ISO 8601 datetime | Yes | Timestamp of most recent message |
| messages | (UserMessage \| SystemResponse)[] | Yes | Ordered message history |
| role | enum: "student" \| "teacher" \| "auto" | Yes | Session-level role setting |
| expired | boolean | Yes | Whether session has passed 30-minute inactivity timeout |
| subject | string | No | Identified mathematical subject (e.g., "logarithms", "geometry") |

**State transitions**:
- `active` → `expired`: When `lastActivityAt` is more than 30 minutes ago
- `active` → `active`: On each new message (updates `lastActivityAt`)
- `expired` → `active`: On new message (creates new session, archives old)

**Lifecycle**:
1. Session created on first message
2. Each message updates `lastActivityAt`
3. On page load, check if existing session is expired
4. If expired, archive and create new session
5. If active, restore conversation from localStorage

### PedagogicalContext

Internal state used to maintain teaching continuity across a conversation.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| currentSubject | string | Yes | The mathematical subject being taught |
| teachingPhase | enum: "slow-foundation" \| "fast-derivation" \| "slow-reflection" | Yes | Current phase in slow-fast-slow rhythm |
| gradeLevel | string | No | Inferred or selected grade level (e.g., "G8", "G10") |
| metaphorsUsed | string[] | No | Metaphors already deployed in this session (avoid repetition) |
| ganJueChecked | boolean | Yes | Whether a "Gan-Jue" feeling check has been performed in current phase |
| examplesReferenced | string[] | No | markdown_output examples already cited |

## Relationships

```
ConversationSession 1 ────* UserMessage
ConversationSession 1 ────* SystemResponse
UserMessage 1 ────* ImageAttachment
ConversationSession 1 ──── 1 PedagogicalContext (ephemeral, not persisted)
```

## Validation Rules (from Requirements)

- **FR-004**: Combined text + image input validated atomically
- **FR-010**: Session expiration checked on every restore (30-minute inactivity)
- **FR-013**: LLM vision capability cached per session to avoid repeated detection
- **FR-021**: LaTeX syntax validated before rendering; fallback to plain text on parse failure
