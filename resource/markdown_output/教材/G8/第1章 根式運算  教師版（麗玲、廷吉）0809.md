文本部分詳細解釋了如何利用這些面積關係來建立 $a^2 + b^2 = c^2$ 的等式。

**引導步驟：**

*   **(1) 藍色正方形的面積表達式：**
    $$\text{藍色正方形} = \text{虛線的正方形} - 4 \times (\text{紅色直角三角形的面積})$$
    （公式中使用了 $c, a, b$ 等變數。）

*   **(2) 兩個綠色正方形的面積表達式：**
    $$\text{兩個綠色的正方形} = \text{虛線的正方形} - 4 \times (\text{紅色直角三角形的面積})$$
    （公式中使用了 $a, b, c$ 等變數。）

*   **(3) 關係建立：**
    由 (1) 和 (2)，可以得出兩者之間的關係，暗示了邊長平方的關係。

*   **(4) 直接展開與化簡：**
    文本展示了如何將 (1) 的算式直接展開化簡，並推導出結論：
    $$\text{（藍色正方形面積）} = \dots$$
    $$\text{（綠色正方形面積）} = \dots$$
    最終，通過比較這些表達式，證明了：
    $$c^2 = a^2 + b^2$$

**結論 (Conclusion)：**

*   文本總結了數學推導的結果：**「直角三角形斜邊長的平方會等於另外兩股邊長的平方和，這種邊長關係被稱為勾股弦定理或畢氏定理。」**

*   此處開始進行反證過程，使用平方運算來證明等式不成立。
*   步驟展示了 $(\sqrt{5} + \sqrt{3})^2$ 的展開：
    $$(\sqrt{5} + \sqrt{3}) \times (\sqrt{5} + \sqrt{3}) = \underbrace{\sqrt{5} \times (\sqrt{5} + \sqrt{3})}_{\text{或 } \sqrt{5} \times \sqrt{5} + \sqrt{5} \times \sqrt{3}} + \underbrace{\sqrt{3} \times (\sqrt{5} + \sqrt{3})}_{\text{或 } \sqrt{3} \times \sqrt{5} + \sqrt{3} \times \sqrt{3}}$$
    $$= \sqrt{5} \times \sqrt{5} + \sqrt{5} \times \sqrt{3} + \sqrt{3} \times \sqrt{5} + \sqrt{3} \times \sqrt{3}$$
    $$= 5 + \sqrt{15} + \sqrt{15} + 3$$
    $$= (5) + (\sqrt{15} + \sqrt{15}) + (3)$$
    $$= (5 + 3) + 2\sqrt{15}$$
    $$= 8 + 2\sqrt{15}$$
*   **結論：** $\sqrt{5} + \sqrt{3}$ 的平方不是 $8$，因此 $\sqrt{5} + \sqrt{3} \neq \sqrt{8}$。

**12. $\sqrt{5} - \sqrt{3}$ 會是 $\sqrt{5} - 3 = \sqrt{2}$ 嗎？ 用平方來看！**
*   此處也進行反證過程：
    $$(\sqrt{5} - \sqrt{3}) \times (\sqrt{5} - \sqrt{3}) = \underbrace{\sqrt{5} \times (\sqrt{5} - \sqrt{3})}_{\text{或 } \sqrt{5} \times \sqrt{5} - \sqrt{5} \times \sqrt{3}} - \underbrace{\sqrt{3} \times (\sqrt{5} - \sqrt{3})}_{\text{或 } \sqrt{3} \times \sqrt{5} - \sqrt{3} \times \sqrt{3}}$$
    $$= \sqrt{5} \times \sqrt{5} - \sqrt{5} \times \sqrt{3} - (\sqrt{3} \times \sqrt{5} - \sqrt{3} \times \sqrt{3})$$
    $$= 5 - \sqrt{15} - (\sqrt{15} - 3)$$
    $$= 5 - \sqrt{15} - \sqrt{15} + 3$$
    $$= (5 + 3) - 2\sqrt{15}$$
    $$= 8 - 2\sqrt{15}$$
*   **結論：** $\sqrt{5} - \sqrt{3}$ 的平方不是 $2$，因此 $\sqrt{5} - \sqrt{3} \neq \sqrt{2}$。

### 二、推導結論（總結）

根據上述的計算過程，教材得出以下數學結論：
*   **結論：當 $a > b > 0$ 時，**
    1.  $\sqrt{a} + \sqrt{b} \neq \sqrt{a+b}$
    2.  $\sqrt{a} - \sqrt{b} \neq \sqrt{a-b}$

### 二、 解題過程 (Solutions)

**1. 第26題的解答步驟：**
*   **原理說明：** 因為車子等速，所以時間與距離成正比。
*   **畢氏定理應用（計算乙丁的距離）：** 由畢氏定理可得 $\text{乙丁}$ 的距離：
    $$\text{距離}^2 = \text{乙丙距離}^2 + \text{丙丁距離}^2$$
    $$2^2 = 8^2 + 15^2 = 64 + 225 = 289$$
    因此 $\text{乙丁}$ 的距離 $= \sqrt{289} = 17$。
    （註：解題中將 $2^2$ 寫成了 $2$ 但根據上下文推測應為 $8^2 + 15^2$，並計算了 $\sqrt{289}=17$）
