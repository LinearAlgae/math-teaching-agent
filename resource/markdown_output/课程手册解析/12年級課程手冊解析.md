前 言 
    一直以來，數學被認為是一門最難學的課程，也常常被認為跟現
實生活嚴重脫節的知識，可是，她卻是眾所公認的科學之母，造成這
個落差因素很多，也不是一個三言兩語足以道盡的議題。任何知識，
只要有一定的張度，就會有一定的難度，就一位數學老師的基本職責，
應該竭盡所能，讓學生享受跨越數學難度的成就感所帶來的學習樂趣，
讓國民義務階段的數學知識成為一種國民的基本素養，一種與生活息
息相關的必備知識。終生學習是一種生命的態度，數學老師們更需要
秉持這種態度，不斷探索我們習以為常的數學與數學教學，如此，方
能改善眼前數學教育的困境。 
很幸運的，我有許許多多的機會，讓我察覺到自己對國民教育階
段數學認知的淺薄，也因此而得以自我鞭策並不斷拓展對數學教與學
的視野，這個過程讓我樂在其中，因此，很想分享我對國民教育階段
數學的觀點，從為什麼要學它，以及，學了之後有甚麼用的角度，來
思考我們應該給學生學甚麼樣的數學。趁著分析剛頒布的綱要課程手
冊，將個人的淺見做標示與註記，希望這些資料能幫助現場老師對數
學的學科本質有更清楚的認識，以及匯集一些心中的疑問作為往後課
綱編修的參考，敬請指教！

### 一、 數學定理與性質（極限運算性質）

圖片上半部包含了關於序列和極限的基本數學推導，主要說明了極限運算的幾種基本性質。

#### 1. 前言說明
開頭文字指出：如果一個序列 $\langle a_n \rangle$ 找不到一個數 $a$ 使得 $a_n$ 逼近，且可以跨過所有「差距」的標記，那麼我們就認為該序列**不收斂**（或發散）。

#### 2. 極限運算性質（① 至 ⑤）
圖片列出了五個關於極限的基本運算規則：

*   **① 乘法法則：** $\lim_{n\to\infty}(a_n b_n) = a b$
*   **② 常數法則：** $\lim_{n\to\infty}(a^n) = a$
*   **③ 乘法法則（擴展）：** $\lim_{n\to\infty}(a_n \cdot b_n) = a \cdot b$。這裡進一步展示了乘積的更複雜形式，涉及絕對值和極限的應用：
    $$\lim_{n\to\infty}\frac{a_n b_n}{a^n b^n} = a b$$
    （並給出更嚴謹的證明步驟，涉及到 $\frac{|a||b^n|}{|a^n||b^n|} \to 0$ 等形式）。
*   **④ 商法則：** $\lim_{n\to\infty}\frac{b_n}{a_n} = \frac{b}{a}$。這部分展示了如何通過代入和利用極限性質來證明商的極限。
*   **⑤ 序列的極限：** 如果 $a_n \to c$ 且 $b_n \to b_n$，則 $\lim_{n\to\infty} c^n = b$。（註：原文中可能存在排版錯誤，實際表達的是關於兩個收斂序列相除的性質，即如果 $a_n \to a$ 和 $b_n \to b$，則 $\lim a_n/b_n = a/b$）。

### 第一部分：數學推導與公式（頂部文字）

這部分展示了將標準橢圓方程進行旋轉後，如何得到一般二次型方程的推導過程。

**1. 初始設定與變換：**
*   **中心點：** 中心在 $(h, k)$。
*   **座標變換（旋轉）：** 使用三角函數描述了座標的轉換關係：
    $$x = h + a\cos\theta$$
    $$y = k + b\sin\theta$$
    其中 $\theta$ 為橢圓的旋轉角。

**2. 旋轉公式應用：**
圖中接著展示了將 $x$ 和 $y$ 進行旋轉後的新座標 $x'$ 和 $y'$ 的表達式（雖然符號略有混亂，但意指旋轉公式）：
$$x' = x\cos(\theta) + y\sin(\theta)$$
$$y' = -x\sin(\theta) + y\cos(\theta)$$

**3. 橢圓方程的推導：**
*   起始點是標準橢圓方程：$$\frac{x'^2}{a^2} + \frac{y'^2}{b^2} = 1$$
*   通過將 $x'$ 和 $y'$ 代回旋轉後的表達式，將其轉換為新的坐標系 $(x, y)$，推導出一個關於 $x$ 和 $y$ 的一般二次型方程：
    $$\left(b^2\cos^2\theta + a^2\sin^2\theta\right)x^2 + \left(b^2\sin^2\theta + a^2\cos^2\theta\right)y^2 + \left(b^2-a^2\right)\cos\theta\sin\theta xy = a^2b^2$$

**4. 一般式總結：**
*   將上述方程整理為一般二次型形式：
    $$Ax^2 + Bxy + Cy^2 = D$$
*   圖片最後給出了這些係數之間的關係：
    *   $A = b^2\cos^2\theta + a^2\sin^2\theta$
    *   $C = b^2\sin^2\theta + a^2\cos^2\theta$
    *   $B = (b^2-a^2)\cos\theta\sin\theta$
    *   $D = a^2b^2$
*   進一步說明了係數的關係：$$A+C=a^2+b^2 \text{ 且 } D=a^2 \cdot b^2$$

### 三、 理論解釋與圖表

#### 【函數】 (Functions/Mapping)
*   **核心觀念：** 長久以來的函數被簡約為一種「對應」的關係，但必須附加一條規定：在定義域的每一個元素會有且只能有一個在對應域上的元素（稱為函數值）。為了合理化這個額外的規定，衍生了各種定義方法。

#### 【變化】 (Transformation)
*   **觀察與記錄方法：** 介紹了進行變化的觀察與記著步驟，強調每一筆資料至少包含兩個項目：一是資量的編碼 $(A)$，另一為欲觀察項目的編碼 $(B)$。
*   **比較與篩選：** 當完成記著後，在比較時需要依 $A$ 編碼挑選兩筆資料進行 $B$ 編碼的比較（如選擇 $A_1, A_2$ 挑出 $\left(A_1, B_1\right)$ 和 $\left(A_2, B_2\right)$）。
*   **有效性判斷：** 檢查資量中是否存在「無效的資量」（即 $A$ 存在但 $B$ 不存在），應予剔除。
*   **篩選目的：** 如果同一 $A_i$ 編碼下有多筆資料（如 $\left(A_i, B_{i1}\right)$ 和 $\left(A_i, B_{i2}\right)$），必須進行「篩選」，只選取一筆，以確保其 $B_i$ 能與其他筆的 $B_j$ 進行有效比較。
