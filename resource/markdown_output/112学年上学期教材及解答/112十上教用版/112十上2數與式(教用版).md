### 一、 標題與核心主題

### 二、 主要文字內容與數學論述

這段文字旨在從實際需求出發，引入數字的起源和分類。

1.  **數字的產生與定義：**
    *   開頭指出：「數，因使用需求而產生。」
    *   定義了「正實數」是形容所有實際可見長度的數學概念。

2.  **範例一：整數與非整數的區分 (以量度為例)**
    *   描述了一個情境：阿銘量銅條的長度，如果剛好落在公分的位置，則量到的長為公分。（暗示這屬於整數）。
    *   進一步描述了如果長度落在刻度和公分之間（例如 $\frac{1}{45}$ 公分），量到的長為 $\frac{2}{45}$ 公分。
    *   提出分類問題：這類數是「整數」還是「非整數」？（通過方框標記提問）。

3.  **概念的發展：分數與有理數的引入**
    *   根據上例，提出將整數等分可以量到的數稱為「分數」（Fraction），因為它是以比例形式呈現的。
    *   定義了「有理數」(Rational Number)：由於其字義具有「有理性、明理」的特質，因此被譯為「有理數」。

4.  **小數與十進位：**
    *   定義了「小數」（Decimal）：分數中將整數刻度不斷十等分這一類的數，是我們常用的表現方法，故稱之為「小數」，並指出它是十進位。

5.  **對無限的討論：**
    *   提出問題：「十等分的刻度可以用來表現等分的數嗎？不可以。」
    *   解釋原因：因為無法將此概念擴充到整數次方，因此引出了實數是實際存在的數，以及進一步探討無窮的概念。

### 三、 數學符號與圖表結構

#### 2. 解法一：代數思維 (Algebraic Thinking)
此方法要求學生分別找到兩個絕對值的臨界點，並根據這些分段關係討論去絕對值後的方程式。

*   **第一段：** 當 $3x < -$，求解時需要處理 $|2|x - 3|$ 和 $|7x - 1|$ 的符號。

*   **第二段：** 當 $-3 \le x < 2$，討論不同絕對值項的關係。
    *   結論是：此時無解。
*   **第三段：** 當 $x \ge 2$，討論不同絕對值項的關係。
    *   計算過程涉及將絕對值拿掉，得到 $\frac{2}{17}x \Rightarrow 3x$。

#### 3. 解法二：幾何思維 (Geometric Thinking)
此方法以視覺化的方式解釋了絕對值的意義。

*   **類比：** 想像成到座標 $x$ 的距離加上到座標 $y$ 的距離等於某個點的關係（橡皮筋的例子）。

兩種方法最終得出解為 $x = -4$ 或 $x = 3$。

    * A、B、C 為圓 $O$ 上的三點。
    * AB 被定義為圓的直徑，O 為圓心。
    * CD 垂直於 AB (AB $\perp$ CD)。
* **參數設定:** 引入變量 $a$ 和 $b$ 來標註線段長度：
    * $AD = a$
    * $BD = b$
* **目標問題:** 要求比較圓心到點 C 的距離 ($OC$) 和直線 CD 的長度 ($CD$)。
* **探究問題:** 提問「你覺得 $OC$ 和 $CD$ 哪一段比較長？」，並進一步探討如果移動點， $OC$ 和 $CD$ 是否可能相等，以及何時會重合。

#### 4. 數學註釋（常識）
* **符號解釋:** 對於數學中的「$\Rightarrow$」（雙向推論或等價關係）進行了註釋，指出它表示從左方證據可以推論到右方的結果，反之亦然。
* **警示:** 強調這類雙向推論並非在所有情況下都成立（以「白馬是馬，但馬卻不一定是白」作為例子）。
